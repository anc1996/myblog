## 任务与记忆协作

每份任务包只包含：目标、文件归属、输入合同、允许的 IO/写入、验收命令和停止条件。
通常一个实现者加一个按需审查者；独立边界才并行，最多三个子代理，
共享数据库测试串行。主代理保留关键路径任务，完成后及时关闭代理。
发布/权限/身份/跨存储合同变更需要独立审查；普通函数测试不逐个触发全队审查。

ai-memory 标记为 `default/anc1996-myblog`，与旧项目 `default/wagtailblog2` 分开。
静态客户端每次传两个 scope 字段；感知会话客户端按实际路由能力使用。
进入相关子系统前检索既有决定、已知失败和未完成证据；命中重要页面后读全文并核对当前源码。
活跃任务走原生消息；跨项目通知仅在用户要求时走 `memory_message_send`。
只有明确要求保存时写持久知识；正式项目规则留在 AGENTS.md。
Handoff 仅用于明确结束或用户要求下次接续，不在派发时消费或创建。
