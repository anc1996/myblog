# myblog 代理协作配置

本配置按用户指定的四个模型别名安排工程职责，未声称厂商能力、价格或上下文上限。
`custom` 提供方沿用宿主配置，仓库不包含凭据，不复制旧项目模型目录或 MCP 绝对路径。
主会话由桌面宿主选择；角色文件不能改变已经运行的主会话身份。

## 职责与本轮调用

### 2026-11-27 角色体系重组与 6 阶段标准化流程

因 `gemini-4-argon` 即将退场、且停用旧版 `gpt-6.1-terra` 与 `gemini-3.8-flash-tiered`，项目角色重组为 7 个单一职责角色（新角色需在**新会话**生效并做一次最小烟雾验证）：

| 角色 | 配置模型 / 推理 | 职责边界 | 注意事项 |
|---|---|---|---|
| `pm` | `gpt-6.2-sol` / `high` | 需求收集、需求分析与定级（A/B/C 三档）、框架调研与可验收标准 | 默认只读，不改业务代码 |
| `sol` | `gpt-6.2-sol` / `high` | C 级重大方案设计（架构重组、数据库改表、性能优化、数据迁移、跨存储契约）与交付证据复核 | 重大方案必经 `carbon` 审核；原生搜索关闭，联网走 MCP |
| `carbon` | `gemini-4-carbon` / `high` | **事前高阶逻辑审核与红队破壁**（替代原 `argon` 审查职责）：专审 `sol` 的重大方案，排查并发、锁序、权限与迁移回滚漏洞 | 默认纯只读，不包揽常规编码 |
| `neon` | `gemini-4-neon` / `high` | **复杂工程实现 + B 级前端/常规方案设计**：架构重组、复杂后端/Wagtail 生命周期排错；兼写前端 UI/交互与常规模块方案 | 遵守成本护栏：单文件/常规实现交给 `gemini`；2026-11-24 已实测可用，仍以新会话实际路由为准 |
| `gemini`（含 `default_subagent_model`） | `gemini-4-hydrogen` / `high` | **日常开发主力**：日常需求改动、接口调用、常规模板/样式、定向单测与文档同步 | 本项目最低 Gemini 基线，严禁再用 `gemini-3.8-flash-tiered` |
| `runner` | `gemini-4-hydrogen` / `high` | 批量自动化测试套件执行、静态检查、日志探针与高频验证 | 共享测试库严格串行，不改业务代码掩盖报错 |
| `reviewer` | `gpt-6.1-sol` / `high` | **事后代码与补丁独立审查**（替代已停用 `terra` / `gpt-6.1-terra`）：独立核查高风险实现 diff，按明确指派执行极小补丁核验 | 默认只读，与 Gemini 实现代理形成跨家族独立复核 |

标准研发流程（需求收集 → 需求分析与定级 → 方案设计与审核 → 编码实施 → 测试与代码复核 → 预览确认与受控发布）及 A/B/C 三档分流规则见根目录 `AGENTS.md`。

## 任务与记忆协作

每份任务包只包含：目标、文件归属、输入合同、允许的 IO/写入、验收命令和停止条件。
通常一个实现者加一个按需审查者；独立边界才并行，最多三个子代理，
共享数据库测试串行。主代理保留关键路径任务，完成后及时关闭代理。
发布/权限/身份/跨存储合同变更需要独立审查；普通函数测试不逐个触发全队审查。

ai-memory 标记为 `default/anc1996-myblog`，与旧项目 `default/wagtailblog2` 分开。
静态客户端每次传两个 scope 字段；感知会话客户端按实际路由能力使用。
进入相关子系统前检索既有决定、已知失败和未完成证据；命中重要页面后读全文并核对当前源码。
活跃任务走原生消息；跨项目通知仅在用户要求时走 `memory_message_send`。
只有明确要求保存时写持久知识；正式项目规则留在 AGENTS.md。
Handoff 仅用于明确结束或用户要求下次接续，不在派发时消费或创建。
