## 请重点审核

- PostgreSQL 中的发布状态与 MongoDB 不可变内容版本如何对应，失败重试是否会泄露草稿或引用错误版本。
- 文件读取、HEAD、Range 和续传是否都重新检查权限；媒体历史引用是否能阻止误删。
- 数据库写入与对象上传不能一起提交时，残留对象、重试任务和回收流程是否完整。
- PostgreSQL 支持条件唯一索引后，是否仍完整验证统一锁、幂等、批准 Revision 一致性及真实并发。
- 每个实施步骤是否足够小，是否写清前置条件、验收方法和失败后的处理方式。
- 搜索、Tag、栏目、Archive 是否真正共用公共查询，是否用同一正式版本与权限计算列表、总数和分桶。
- 搜索 A 模式结果少时提供手动展开 B 模式按钮；分块单列 tsvector 目标大幅缩减 GIN 索引（以实测为准）；单快照 REPEATABLE READ 查询。
- 回收站原树占位模型、页面错删后的原树位置恢复功能、冲突处理（父丢失、slug冲突、类型违规）、未发布草稿态保障与后台穿透防御（CustomBasePage 守卫、PageViewSet 接管）。
